# ADR-004：笔刷、规整图形与手写文字直出

- 状态：笔刷与几何工具已实施；第 7 项 PaddleOCR 手写原型因用户体验不达标终止，替换决策见 [ADR-005](ADR-005-incremental-digital-ink.md)。原型代码仍在，免费本地替代尚未通过完整验收。
- 日期：2026-11-08。

## 决定

1. 笔刷新增 `pencil`、`fountain`、`marker`，连同圆珠笔与荧光笔由前端 Canvas2D 渲染。无新增运行时依赖；渲染确定，不随重绘产生随机纹理。Rust 闭合枚举同步添加三种判别值。
2. JSONML 的 `stroke.brush` 扩展枚举，笔画采样、命令日志与包结构不变；旧笔迹缺省值仍为 `pen`。这是早期格式的加法扩展，旧构建不认识新枚举时会拒绝解析并保留包，不能用旧构建继续编辑含新笔刷的文档。当前不宣称旧客户端能打开新笔刷文档。已有只读新版保护与未知字段拒绝原则不变，发布前需建立正式格式迁移版本策略。
3. 选择、笔刷、文字、图形、擦除共用 `Canvas` 和 `Toolbar`。主画布继续走串行持久化队列；屏幕临时标注的文档与撤销历史由覆盖层 WebView 独占，工具栏只发送定向编辑命令与接收状态。不引入通用事件总线或第二套后端文档。
4. 规范图形直接拖出直线、箭头、矩形、椭圆。手绘规整只在用户开启后保持按下停顿 600ms 时尝试，或选择已有笔迹后显式触发。保守几何拟合只覆盖直线、矩形、椭圆；不会声称是通用图形识别引擎。
5. 透明 WebView 的 CSS `backdrop-filter` 不保证能采样底层其他应用。移除去色／模糊的虚假控件，只暴露真实 alpha 压暗；待原生合成能力验证后再增加滤镜。
6. 窗口和穿透变化通过主线程调度执行，前端仅在原生确认后更新状态；失败明确提示。仅在第一次呼出展示非阻塞使用指南，保持画布启动即书写。
7. 手写文字采用独立书写模式，停顿后原位自动排版，中英文为必需项，中英混写为独立验收项。默认无圈选和逐次确认弹窗。实施 PaddleOCR.js 0.4.2 的 Worker / WASM 本机原型，并保留 MyScript 原生 C++ SDK 对比；前者使用笔迹图像，后者使用数字墨迹，交互可以相同。新增 PaddleOCR.js 0.4.2（Apache-2.0）、OpenCV.js 4.10.0-release.1（Apache-2.0）、ONNX Runtime Web 1.24.3（MIT）依赖；PP-OCRv5 mobile 检测与中英识别 ONNX 模型合计 20.5 MiB，以 SHA-256 固定。模型卡为 Apache-2.0，许可文本与 NOTICE 随本地资源分发。运行时本地 WASM 约 11.8 MiB，首次下载是显式开发准备命令，构建和识别不联网。SDK 的 OpenCV Mat 输入用于规避 Worker 中的 DOM 路径，Vite 固定 WASM 后端；CSP 仅增加同源 Worker、同源资源 fetch 和 WebAssembly 编译许可，没有开放外部内容服务或 JS eval。未激活 MyScript 许可，未发送内容到云端。准确率与延迟实测后再定最终引擎。详见引擎调研。

## 验证与限制

- 新笔刷经存储往返、撤销重做与重开测试；几何拟合覆盖误判样本和反向拖拽。
- 工具栏窗口按实际内容尺寸调整，首次帮助、笔刷面板、背景菜单无需在 52px 高窗口中溢出。
- 系统录屏对控件隐藏的支持不由 `sharingType` 设置本身证明；仍需会议软件兼容矩阵。多显示器和全屏行为仍须分别实测。
- 覆盖层内容当前只在进程内保留，收起不删除，退出会丢失。持久化与带入画布尚待后续交付，UI 明确显示“临时标注”。
