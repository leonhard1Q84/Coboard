# ADR-008：Goodnotes 风格图形工作流与一等连接线

- 状态：已实施（核心领域模型、存储往返、画布/覆盖层交互与前端状态）
- 日期：2026-11-10
- 相关文档：[ADR-004](ADR-004-ink-tools-and-handwriting-recognition.md)、[ui-guidelines.md](../design/ui-guidelines.md)、[PRD.md](../product/PRD.md)

## 背景

此前实现存在三项可用性与架构问题：

1. **画笔面板塞入晦涩图形开关**：`停笔规整图形` 仅靠单个图标暴露，且 `autoRecognize` 按钮尚未接通真实后端直出流程，容易在常规书写中造成困惑。
2. **手绘图形缺少免确认的自然转换与完整图元**：单笔手绘轻微未闭合、倾斜的三角形或波浪线、弧线识别不足，用户不得不在画完后二次选中再点击"规整"确认。
3. **连接线未独立成工具**：讲解流程、状态关系和推导图大量依赖连接线，也直接决定后续 `AI-01` 理解画布结构时的语义清晰度。

## 决定

### 1. 画笔面板回归书写职责并采用「绘制并按住」

- 移除 `brush` 弹出层中仅用图标展示的 `停笔规整图形` 与未闭环 `autoRecognize` 开关。
- 在画笔面板保留 `pen`、`pencil`、`fountain`、`marker` 笔刷切换，并以带中文说明的 `role="switch"` 开关暴露 **`绘制并按住`**（`drawAndHold`，默认开启）。
- 使用画笔停顿约 460ms 触发原位规整预览；规整后不抬笔继续拖动可实时缩放与旋转（Hold-and-Adjust），整个过程无需额外弹窗或二次点击确认。

### 2. 图形工具（`S`）默认免确认手绘自动规整并扩展图元

- 工具栏构建组重构为 **`连接线 C` · `图形 S` · `文字 T`**（紧接选择/套索与书写/擦除之后）。
- `图形 (S)` 弹出层提供分段切换：默认 **`手绘自动规整`**（抬笔即无感规整，并支持 6 秒内多笔自动合成为箭头、三角形、矩形或菱形），亦可切至 **`拖放预设`** 直接拖放矩形、椭圆、三角形、菱形、直线、箭头，并附带 `填充底色`（14% 透明底色）与 `矩形微圆角` 开关。
- 扩展基础几何图元与属性：
  - `ShapeKind` 新增 `Curve`（弧线）与 `Wave`（波浪线）。
  - `Shape` 节点新增可选字段：`points`（保留拟合三角形的 3 个真实顶点或波浪线参数/弧线控制点）、`fill`、`corner_radius`、`text`（封闭图形居中文字）与 `rotation`。
  - 针对常见手绘三角形（如顶点微张 `direct <= 0.42 * diag` 或带倾斜角度），结合三边中点覆盖与循环顶点投影拟合保留原始顶点，不再强制拉伸为正三角形。

### 3. 连接线（`C`）升级为一等对象并输出语义图

- 连接线从形状分支中独立，作为画布与覆盖层的顶层工具 `connector`（快捷键 `C`）。
- 支持连接任意对象（`shape`、`paragraph`、`math_block`、`derivation_card`、`image`、`stroke`）的 `top/right/bottom/left`、`auto`（边界射线交点）或 `center` 锚点，也允许起止于画布自由点；提供 `straight`（直线）、`elbow`（圆角折线）、`curve`（平滑贝塞尔曲线）三种路由，单向/双向/无箭头、虚线、弯折控制点与线上居中标签。
- 单选封闭图形时四边浮出快速连接 `+` 控制点：单击向对应方向生成同样式节点并连线，拖动直接拉出新连接线；对象移动时附着连接线以 60fps 随动并随删除级联清理。
- 为 `coboard-domain::Document`（`semantic_graph()`）与前端 `diagramGraph.ts`（`buildSemanticGraph`）提供确定性的结构化节点与边导出，为后续 `AI-01`（画布内容理解）保留零重构的语义边界。

### 4. 存储与兼容性说明

- 上述新增字段与 `ShapeKind::Curve | Wave` 为当前 JSONML 格式的加法扩展，保持 `coboard-domain` 无外部依赖，且无 `points` 时省略序列化，减少旧结构差异。
- 与 ADR-004 一致：不认识新字段或新枚举值的旧版本客户端仍会显式拒绝解析并只读保留原 `.coboard` 包，不会静默丢弃数据；正式发布迁移策略需随版本化升级统一建立。

### 5. 前端 UI 令牌与无障碍约束

- 所有新样式仅引用 `apps/coboard-desktop/src/styles/tokens.css` 语义变量（无硬编码色值），尊重 `@media (prefers-reduced-motion: reduce)`。
- 工具栏和上下文栏按钮显式使用 `type="button"`，切换态直接绑定 `[aria-pressed='true']` / `[aria-checked='true']` / `role="switch"`，避免视觉状态与可访问状态脱节；零新增第三方运行时依赖。

## 验证与限制

- **自动化覆盖**：`coboard-domain` 领域测试与往返/崩溃恢复测试、`vitest` 几何识别/连接线锚点与路由/语义图导出/选择与分组操作测试、TypeScript 类型检查与 Vite 构建。
- **未由自动化替代的验证**：触控板、数位板真实压感与停顿手势下的 460ms `drawAndHold` 阈值舒适度、覆盖层浮动工具栏弹出时的原生窗口尺寸实测，以及长流程屏幕共享演示下的真实误识别率，仍须在桌面交互会话与真机硬件上调优确认。
