# ADR-006：增量空间 DP 与原生后台原型

- 日期：2026-11-09。
- 状态：阶段 2 与 Tauri 原型接入已实现；libochwpro 不进入桌面，正式模型分发与自由书写验收未完成。
- 延续：[ADR-005](ADR-005-incremental-digital-ink.md)。

2026-11-09 复核：UCI UJIpenchars2 全部 20 位测试书写者的 2,480 个孤立字母数字，当前混合字符单字 Top-1 52.66%。这是实际测量，不能用七组合成样例或计算速度抵消。当前模型与移植实现继续视为未通过可用性验收；不启用自动删除笔迹或自动稳定直出。采样一致性缺陷已修复，但原 48 组合成变体仍为 41/48。证据见 [真人评估](../../research/handwriting/human-evaluation.md)。

## 问题与决定

首轮 libochwpro 单字与整行结果不足以作为产品底座。继续改采样密度仍无法解决候选缺失，因此保留其独立研究适配器，桌面增量原型改用仓库已有的 Path-Signature + Sparse CNN 本地推理和二元语言模型。既有模型也不代表已通过真实字迹验收；以可撤销候选方式接入，不自动提交。

1. 在 `coboard-vision-ml::incremental` 实现可替换单字打分器的 Rust 分段器，不新增 production crate 或运行时依赖，不引入前端 WASM/OpenCV。推理使用原生 CPU，未启用 Accelerate。
2. 相交水平包围盒组成空间分量，分量从左到右排列，内部保留采集笔顺。DP 缓存空间半开笔画区间 `(j, i)` 候选；迟到横画合并分量后失效受影响后缀。输出原始笔画索引与 ID，避免把空间顺序当采集顺序。
3. 使用包围盒宽高、内部空隙和候选宽高比惩罚限制跨字合并。对数概率按空间分量数加权，降低不同切分长度的比较偏差；这是开发集启发式，尚未做概率校准。脚本、大小写、数字转移先验结合现有中文二元 LM；几何推断空格，跨空格重置上下文。保留八条 beam、输出五候选，是有界近似搜索。
4. 原生单字模型做四个子栅格相位的加权推理，以减小池化栅格相位偏差；增加计算但仍在本机回放预算内。没有目标文本特判，系数经开发集调试。
5. “稳定范围”仅表示当前 beam 与上次一致的前缀，并排除最后一字；补笔可撤回，不授权自动删除。前端点击候选后逐点核对最新笔迹，以一个编辑事务删除原笔迹并插入文字，支持一次撤销恢复。
6. 后台模型按需加载，`spawn_blocking` 与单并发信号量执行；每窗口有界会话、序号校验、变化后缀和幂等重试，Channel 返回候选、稳定 ID 范围及计算指标。前端最多一个在途请求，后续抬笔合并；过期、取消、移动、删除和撤销不允许旧结果转换。书写热路径不等待 IPC。
7. `research/handwriting/ochwpro-probe` 保持独立 Cargo workspace，固定上游提交 `54c326d33d86cc0754dbea5a36c1448682c8202c` 与 lockfile。Candle 0.9.2（MIT/Apache-2.0）不进入桌面依赖图；上游根 LICENSE 为 MIT、manifest 标 Apache-2.0，代码与模型再分发仍需澄清。原生实验模型沿用已存在的本地资产，权重不复制进仓库／应用，分发许可未确认，不据此发布。

## 验证与限制

2026-11-09 英文连写补充：空间区间候选现在可以是一条连续笔迹内解码出的完整小写词。最多 25 个虚拟切点、300 个区间，结合本地单字形状、几何约束和英文词频前缀搜索；词表为 wordfreq 3.2 固定提交派生的 CC BY-SA 4.0 数据，随嵌入数据附带 Robyn Speer 署名、上游声明、许可链接与变更说明，无新增运行时依赖。原笔画、文档命令和撤销边界不变，继续手动选择候选。用户 hello 及 18 个同轨迹变体均返回 hello；它们是开发回归，非独立词准确率。原 hello 的 Rust 会话 p95 130.42 ms，未含 IPC/显示；最慢变体 p95 209.16 ms，未全数通过 200ms 计算预算。原 48 组仍 41/48。多笔连写、词表外单词与英文长句未验收，当前实验状态不变。来源、完整记录、构建和限制见 [英文连写评估](../../research/handwriting/connected-evaluation.md)。

七组原始合成样例最终正确，48 组开发组合变体通过 41 组，仍有“中／巾”和大小写歧义；这些不是独立真实笔迹。M4 release 的七组热态更新 p95 为 3.90–30.71 ms，未测端到端显示 p95。实际窗口已验证候选／转换／撤销链路，未完成多人字迹、跨行、连笔、长句与内存峰值验收。完整证据与命令见 [当前报告](../development/incremental-handwriting-prototype.md)，保留 [libochwpro 历史基线](../development/ochwpro-handwriting-baseline.md)。

## 英文连写几何修订

单笔词内分段继续维持 25 个切点／300 条区间的有界预算。末尾 g/j/y 可在具有右侧字形主体的条件下向左回勾；圆形字母的连接线不沿用窄印刷体宽高阈值。字形证据、词表前缀和拒绝门槛继续生效，没有目标单词特判或新依赖。这来自用户 memory 的开发回归，不能推广为英文自由书写验收，见 [修复记录](../../research/handwriting/memory-evaluation.md)。


goal 反馈后修订：短词含上伸和下伸笔画时入口最小宽高比为 1.1；在归一化的 512 点工作副本上切分，允许有严格方向、长度和总弧长预算的字间空连接边。词频作为较弱先验，权重改为 0.10；仍须每个字母都有局部模型证据，没有词级目标特判。原始点与编辑命令不变，无新依赖或平台边界变化。三份用户轨迹及其 54 个变体为开发集，57/57 正确不能替代独立手写验收；计算 p95 最高 246.69 ms，尚未全面达标，见 [联合修复记录](../../research/handwriting/goal-evaluation.md)。


“我们”误作 among 后修订：同一原笔迹内增加最多 6 字、8 beam 的中文路径，逐字计算既有中文上下文，并与英文分支共享相同虚拟切点上的区间 logits 缓存（总计仍最多 300 个不同区间）。中文字形使用混合字符证据，不能借英文词表强制解释；候选分数尚未完成跨脚本校准。模型类别先选择前 100 再排序，等价性由固定对照测试验证，未换模型或改变 logits。无新增依赖、平台边界或文件格式变化。四条用户实际轨迹仍只是开发集，当前结论见 [中文连笔修复记录](../../research/handwriting/mixed-connected-evaluation.md)。

## 2026-11-09：多笔连写与候选竞争修复

取消词内切分必须只有一次 pen-down 的限制。对多笔宽区间采用保留抬笔边界的时间切分，并补充水平空间切片以覆盖迟到点画、横画和跨字回勾；只在推理副本中切分。精确同端点续写可合并工作路径，因端点重合而不新增几何边；其他抬笔绝不连成墨迹。两个时间分支共享最多 300 个区间，空间分支额外最多 300 个区间；缓存键包含全部点和笔画边界。每段依然返回全部原始笔画 ID，不改变转换、撤销、持久化及后台串行边界。单行仍是明确的实验范围，多笔连写不再是禁用范围。

空间组件不再因擦边水平重叠而必然级联硬合并，点画吸附优先关联最近的原始主笔，补充短横画与竖画窄间隙容差。较宽组件仍保留完整单字候选，并与多字路径竞争。英文分笔路径复用现有 Trie 的有界前缀势函数；不产生模型没有给出的字母。大小写连续转移使用相同奖励，宽高比只约束跨组件合并，字高提示只比较同一 Latin 段的历史字高，避免拿汉字高度惩罚英文大写。汉字类别加入现有 LM 的有界弱一元先验，不删除生僻字或独立部首类别。

主相位首选达到 0.85 才跳过三个辅助相位；否则保留原加权集成。卷积/池化工作数组在九层之间复用容量，每层完整初始化可访问区域，不引入共享可变模型状态、线程不安全缓存或新依赖。所有词级数值继续作为启发式排序分数，尚未做跨脚本概率校准。修复后的完整评测、逐样本新增失败与性能条件见 [修复回放](../../research/handwriting/decoder-repair-evaluation.md)。
