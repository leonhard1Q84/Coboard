# ADR-005：终止 PaddleOCR 直接书写原型，验证免费本地笔画识别

- 日期：2026-11-08。
- 状态：用户要求免费、本地；已完成系统 Vision 与汉字笔画识别器的有界实验，尚无候选通过完整替换验收。MyScript 原生仅作商业备选，不再作为推进前置条件。
- 范围：替代 [ADR-004](ADR-004-ink-tools-and-handwriting-recognition.md) 第 7 项的直接书写识别选型，不改变笔刷、图形及截图取字的决策。

2026-11-09 续：已实现独立的增量空间 DP + libochwpro 回放实验；计算耗时达标，单字及中英混写准确率未通过，尚未切入桌面。见 [ADR-006](ADR-006-spatial-dp-handwriting-prototype.md) 与[实验报告](../development/incremental-handwriting-prototype.md)。

## 原因

用户明确反馈当前 Coboard Ink Preview 完全不可用，不能接受 1.2 秒延迟，要求更换方案。旧代码 `HandwritingSession` 默认在最后一次抬笔后等待 1200ms，之后才启动图像识别；历史 54–86ms 合成样例只是推理诊断，不是用户感知的端到端耗时，更不能证明真实手写准确率。

只把 1200 改为更小的常量，仍然是整组笔迹先停顿、再栅格化、再识别、再一次性替换；过早替换还会把尚未完成的中文拆开。此优化不作为本次替代方案。

## 决定

1. 直接书写的目标改为持续处理笔画、后台更新候选，不增加“停笔 1.2 秒后才开始识别”的应用等待。用户进一步明确坚持**免费、本地**，因此不再把缺少 MyScript SDK 当作停止调研的理由；iinkJS / iinkTS 的云端识别不符合本次要求。
2. 前端即时笔迹不等待识别或 IPC。候选只是临时视图，不立即删除原始笔迹；允许在同一字词内继续补笔，取消、撤销、移动或切换模式使过期结果失效。稳定结果才通过现有编辑命令原位转换；一次转换可撤销恢复对应笔迹。具体 SDK 稳定性信号及分段接口取得包后核实，不凭空假定接口。
3. 单纯缩短旧定时器不视为替换完成。所有候选按准确率、补笔稳定性及端到端延迟验收；纯推理快不代表可用。普通画笔、离线编辑、保存和屏幕标注继续使用现有实现。
4. 先在 macOS arm64 独立回放验证，再决定是否接入 Tauri。本轮 Vision 在三组合成样例均识别错误；`hanzi_lookup` 的规范单字对照正确，但非规范笔顺失败，且没有英文词、自由整行分段和混写能力。Zinnia 仅核对公开接口，未实测。结果和复现代码见 [本地候选验证](../development/local-handwriting-evaluation.md)。目前不增加应用依赖或不可运行的适配层。
5. 不把“孤立汉字候选器”包装成完整自由手写平替，也不以 Goodnotes 公开自研引擎介绍冒充可复用 SDK。旧原型代码暂留作回归证据；本轮没有接入新应用引擎或启动替换版 Ink Preview。

## 商业备选（已暂停，不阻塞免费路线）

- macOS arm64 原生库、头文件、最小示例及对应 API 文档；x64 包供后续兼容验证。
- 简体中文和英文识别资源，开发许可及离线运行条件。
- 确认中文与拉丁词混写、补笔、跨行、增量结果、线程要求、取消与资源释放接口。
- 确认包体积、许可和正式再分发条件；商业方向偏好不等于接受合同或购买授权。

先前整理的 [厂商申请稿](../development/myscript-sdk-request.md) 保留为备用，不要求用户申请后才能继续。本次没有注册、购买、接受合同或向厂商发送消息。

## 验收目标（尚未测量，不是性能承诺）

| 项目 | 替换版目标与测量边界 |
| --- | --- |
| 即时书写 | 指针到墨迹保持前端路径，不等待识别、IPC、磁盘或网络 |
| 后台识别 | 书写时增量处理；不等待固定长停顿才开始整组识别 |
| 候选反馈 | 最后一笔抬起到候选在屏幕上可见，热态 p95 ≤ 200ms；含排队、桥接、识别和下一次绘制 |
| 稳定文字 | 完整字词最后一笔抬起到原位稳定排版，热态 p95 ≤ 300ms；未达标即不通过，不用更快的临时候选冒充完成 |
| 冷启动 | 首次启用、资源准备及首次结果分别记录，不混进热态指标，也不阻止继续书写 |
| 准确率 | 真实中文、英文及中英混写分别报告字词错误、空格标点、断行和过早拆字；合成的 HI、中文三个样例不算通过 |
| 连续补笔 | 识别期间继续写、较慢的中文多笔画、相邻字词与跨行均不丢笔；错误候选可更新，旧结果不覆盖新笔迹 |
| 失败与撤销 | 初始化失败、取消、过期结果和识别失败保留笔迹；一次撤销恢复整次转换 |

基准记录机型、系统、SDK 与语言资源版本、构建模式、输入设备、样本集和样本数；分别报告冷／热态、候选／稳定文字 p50 / p95、准确率、内存与包体积。必须经过实际 macOS 窗口验证后，才能重新启动并把 Ink Preview 交给用户试用。目标是否可达取决于实际包与真实笔迹测量；不引用厂商营销数字代替本项目验证。
