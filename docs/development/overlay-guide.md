# 屏幕讲解操作指南

## 先选共享方式

- **共享整个屏幕**：按 `⌥Space` 或主窗口右上角“覆盖层”，在其他应用上方讲解。
- **只共享一个窗口**：共享 Coboard 主画布窗口。覆盖层不会自动进入其他应用的窗口共享画面。
- 工具栏尝试对采集隐藏，但不同会议软件表现不同；不能保证观众看不见。可用“收起工具”缩小控件。

## 一次典型讲解

1. 打开要讲的网页或文档，呼出覆盖层，直接画。
2. 点画笔按钮，选圆珠笔、铅笔、钢笔、记号笔；荧光笔是单独工具。颜色 1–4、粗细 `[ / ]`。
3. 要翻页或滚动原应用，点“绘制中”切换为“操作原应用”，或按 `⌥P`。工具栏始终可点。再次切换即可继续书写；点击绘图工具也会请求恢复绘制。
4. 背景太花，点“背景”调压暗，或选透明、柔和、专注预设。在绘图区按住反斜杠临时看底图，松开恢复。
5. 演示指向用 `L` 激光，轨迹自动消失；内容标注用画笔，收起再呼出仍在。
6. 结束点“结束”或按 `⌥Space`。收起不等于清屏。

## 图形与编辑

- 点图形按钮或 `S`，选择直线、箭头、矩形、椭圆，按下拖出，松开完成。反向拖动同样可用。
- 在画笔面板开启“停笔规整”，画直线、矩形、椭圆后**保持按下停顿约半秒**，看到规整预览再松开。不开启时保持自由笔迹。
- `V` 选择笔迹、图形或文字，拖动移动；已选笔迹可用“规整”转换。无法可靠拟合时保留原笔迹并提示。
- `T` 后在内容区域点一下输入文字；Enter 完成、Shift+Enter 换行、Esc 取消。中文组字期间不触发工具快捷键。
- `E` 整笔擦除；⌘Z / ⇧⌘Z 撤销重做。删除所选用 Delete；清屏先确认，清屏后仍可撤销。
- Esc 优先取消手势／选择，再按可收起。主画布空格平移、双指平移、捏合缩放；屏幕标注不平移，保持对齐底层应用。

## 内容保存

独立画布自动保存，以“已保存”状态为准。屏幕标注是临时内容，退出应用会丢失；不能把收起覆盖层当成保存。屏幕标注持久化、截图取材、素材带入画布尚未完成。

## 手写文字

**当前状态：旧 PaddleOCR 试用已被用户否决，正在验证免费本地替代。系统 Vision 和汉字笔画候选器已完成有界实验，但新引擎尚未接入，下面仍是旧版应用行为。** 决策与验收目标见 [ADR-005](../decisions/ADR-005-incremental-digital-ink.md)。

点“手写文字”或按 `W`，在原处直接手写中文、英文；最后一笔抬起后停顿约 1.2 秒，后台识别成功即自动转文字，无需圈选、校正弹窗或确认。继续落笔会延后转换；切回画笔 `P` 则保留待转换笔迹。首次使用准备模型不阻塞输入。

- 全程本机处理，模型和运行时随应用打包；无需联网或账号。
- 未认清、置信度低、检测漏笔或推理失败时保留整组笔迹。普通画笔不会自动识别。
- `⌘Z` 撤销一次自动转换会恢复整组原笔迹，再按撤销逐笔书写；重做可回到文字。
- 转换后用 `V` 双击文字更正，或用 `T` 点击编辑。当前使用画布默认文字样式；没有自动合并已经转换的上一段，也没有识别公式。
- 当前为 PaddleOCR PP-OCRv5 mobile 原型。WebKit 的合成中、英笔迹已跑通，混写 `中 API 30` 输出为 `中API30`，空格未完整保留；真实连笔、多人字迹、换行、专有名词和速度尚未完成验收，不能承诺 Goodnotes 同等准确率。

旧版独立试用可用 `./script/build_and_run.sh --preview` 构建运行，应用名为 **Coboard Ink Preview**；此命令目前仍构建旧 PaddleOCR 原型，不会自动获得 MyScript。它使用单独笔记目录，不覆盖原来的 Coboard。已有试用实例运行时脚本会拒绝重启，避免丢掉临时标注。

引擎、授权与实测记录见 [引擎调研](handwriting-engine-research.md)。
