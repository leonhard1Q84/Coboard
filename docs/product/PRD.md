# 功能规格（PRD）

定位与非目标见 [positioning.md](positioning.md)，阶段安排见 [roadmap.md](roadmap.md)。编号用于实现跟踪和测试验收。

**优先级**

- **P0**：屏幕共享即时讲解闭环 + 启动即书写。缺任何一项，产品不成立。
- **P1**：差异化取材与沉淀，以及日常使用所需的基础能力。
- **P2**：增强功能；在 P0、P1 稳定之前不开工。

## 性能与可靠性关注点

| 关注点 | 目标方向 | 验证方式 |
| --- | --- | --- |
| 启动到落笔 | 窗口出现即可书写 | 测量冷 / 热启动到第一笔可见的耗时 |
| 呼出与切换 | 快捷键到覆盖层可绘制接近即时；穿透切换无感 | 测量按键到可落笔、模式切换延迟 |
| 书写 | 笔迹跟手，后台任务不阻塞绘制 | 测量输入到显示延迟与连续书写帧耗时 |
| 屏幕共享 | 观众端清晰、无闪烁 | 在兼容矩阵中录制观众端画面 |
| 大画布 | 缩放、平移和选择流畅 | 约定对象数、笔迹量下基准测试 |
| 暂存与恢复 | 增量保存；异常退出恢复已持久化内容 | 写入中断、进程强杀与重开场景 |
| 资源 | 控制内存、CPU、GPU 和耗电 | 分别测量空闲、书写、导入和 AI 状态 |

各项指标以 Apple Silicon 基线机型实测；界面"已保存"对应明确的持久化落盘状态。
