# 产品定位

## 一句话

**Coboard 是 macOS 上为屏幕共享而生的即时讲解工具**：开会共享屏幕时，随时在任何应用上方圈画、取材、压暗背景展开推导；需要一块干净的板时，打开画布窗口一笔就能写。讲完的内容可以沉淀、整理、导出。

## 目标用户与场景

| 用户 | 典型时刻 | 现在怎么做 | 痛点 |
| --- | --- | --- | --- |
| 技术 / 方案讲解者 | 视频会议中共享浏览器、IDE、设计稿讲方案 | 鼠标乱晃、"看这里"；或切到 PPT | 没法在原内容上标重点；切换打断节奏 |
| 理工科教师 / 助教 | 在线课讲论文、PDF、公式推导 | iPad + Goodnotes 投屏，或 Mac 截图后再标注 | 设备割裂；公式要重新抄 |
| 培训 / 售前 | 屏幕演示产品、边讲边画流程 | Presentify / ScreenBrush 画完就没了 | 标注不可编辑、不可沉淀 |

核心任务（JTBD）：**"我正在共享屏幕讲东西，想立刻把观众注意力拉到某处，并在原内容旁边展开推导，而不打断讲解。"**

## "既要又要"：两个空间，一套工具

1. **屏幕覆盖层**（共享整个屏幕时）：在任何应用上方书写、激光指示、圈取文字 / 公式成浮动卡片、拉高蒙版把屏幕变成黑板。
2. **画布窗口**（只共享某个窗口、或需要整块白板时）：启动即可书写的无限画布，和覆盖层共用同一套工具栏、快捷键和笔刷。覆盖层取到的素材可带入画布继续整理。

会议软件"只共享窗口"时采集不到覆盖层，所以画布窗口不是附属功能，而是另一种演示方式的主场。

## 差异化

| 竞品 | 覆盖 | 缺口（Coboard 的机会） |
| --- | --- | --- |
| Presentify / ScreenBrush / ZoomIt 类 | 屏幕圈画、激光笔、聚光灯 | 圈下来的内容不可编辑、不可沉淀 |
| Mathpix Snip / TextSniper / CleanShot X | 截屏转 LaTeX / 文字 | 结果进剪贴板，没有讲解空间 |
| 无边记 / tldraw / Excalidraw | 无限画布 | 脱离原屏幕上下文，书写手感一般 |
| Goodnotes（iPad）/ 华为 IdeaHub | 书写、投屏批注 | 设备割裂；不在 Mac 原内容上方 |

**护城河 = 覆盖层 + 智能取材 + 可调蒙版 + 画布沉淀 的连贯闭环**，而不是任何单项功能。基础白板能力（画布、对象编辑）是入场条件，做到"不拖后腿"即可。

## 非目标（当前阶段）

- 多人实时协作、账号体系、云同步。
- 通用文档编辑器 / PPT 替代品。
- 跨平台（Windows / Linux）。
- 插件系统、模板市场。
- 局域网 iPad 伴侣屏：等"用户主要用什么输入设备书写"有答案后再评估。

## 成功指标（实测后校准）

- 冷启动到可落笔；快捷键呼出到可落笔。
- 一次 30 分钟会议讲解中，无需离开 Coboard 切回其他工具的次数。
- 圈取到可用卡片的成功率与耗时；识别结果被手动纠正的比例。
- 会议软件兼容矩阵中"观众可见 / 控件隐藏"通过的组合数。

## 体验参考

- **ScreenBrush / Presentify**：跨应用覆盖层、穿透切换、激光指示、多显示器。
- **华为 IdeaHub 白板**：画布优先、单条分组工具栏、少量高对比墨迹色、大而短暂的模式反馈。
- **OpenBoard**：桌面标注、浮动工具栏、截图取材、PDF 批注。
- **无边记（Freeform）**：画布生命周期、自动保存、视图定位、场景导览；依据见 `research/whiteboard-app-feature-inventory-2026-11-07.md`。
- **Goodnotes**：快速进入书写、流畅笔触、手绘规整、笔迹录音联动回放。
- **飞书会议**：语音、演示过程与纪要的关联。
