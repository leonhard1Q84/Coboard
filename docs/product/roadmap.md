# 路线图

原则：**先验证最大的未知数（覆盖层手感、WebView 书写延迟、屏幕共享兼容性），再加基础设施**。每阶段交付可运行代码、失败路径测试和真实任务验证；不以功能数量或未实测的性能承诺代替验收。

| 阶段 | 主要范围 | 验收重点 |
| --- | --- | --- |
| **M0：数据地基（已完成）** | Cargo Workspace、JSONML 领域模型、事务编辑 / 撤销重做、SQLite WAL 提交与恢复、BLAKE3 资源池、Tauri + React 入口 | 1,000 条命令后强杀进程，恢复全部已确认状态；详见 `docs/development/m0-foundation.md` |
| **M0.5：启动即书写（当前）** | 画布窗口改为"画布 + 悬浮工具栏"；画笔 / 荧光笔 / 激光笔 / 橡皮 / 选择移动 / 文字 / 公式源码；平移缩放；乐观显示 + 串行持久化；UI 规范与设计令牌 | 启动后一笔即写、不等保存；书写中保存失败不丢笔迹；深浅色；中文输入法 |
| **M1：覆盖层与屏幕共享** | NSPanel 覆盖层、全局快捷键、穿透切换、三层蒙版；同一工具栏组件；工具栏 `sharingType` 隐藏；一键清屏；首次引导 | **会议软件兼容矩阵**（腾讯会议 / 飞书 / Zoom / Teams / Chrome Meet × 整屏 / 窗口共享 × macOS 版本）；呼出到落笔、穿透切换、120 fps 实测；中文输入与焦点不被抢 |
| **M2：屏幕取材闭环** | ScreenCaptureKit 排除自身截图；Vision 文字识别与截图降级；卡片固定、原图核对、连线；剪贴板分享；光标高亮、聚光灯 | 真实完成"打开内容 → 圈取固定 → 穿透滚动 → 调高蒙版 → 连线书写讲解"；分别测量截图、首张卡片与识别完成耗时 |
| **M3：画布沉淀与 PDF** | 素材带入画布、空间索引、场景书签与导览、多画布管理；PDF 浏览与批注；图片导出；公式渲染 | 万级对象 / 多页 PDF 的交互与资源预算 |
| **M4：时间线与录音回放** | 音频分片持久化、离线转写与时间戳；笔迹与音频双向跳转 | 音画对齐、取消与恢复 |
| **M5：AI 理解** | 多服务商流式客户端、内容预算、明确授权、Keychain、候选预览与可撤销接纳 | 断网与模型不可用时仍可创作；范围授权、取消、结果过期检查 |

**待定**：局域网 iPad 伴侣屏、语义布局（LAY-07）、向量检索。需先回答"用户主要用什么设备书写"并有使用数据支撑。
