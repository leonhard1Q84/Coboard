# Coboard UI 视觉与交互规范

适用于画布窗口、屏幕覆盖层和演示模式。实现令牌见 `apps/coboard-desktop/src/styles/tokens.css`。参考基准：华为 IdeaHub 白板的"画布优先 + 单条分组工具栏"，按 macOS 指针与键盘习惯改造。

## 1. 原则

1. **内容优先**：画布占满窗口。界面元素以悬浮方式存在，不切割画布。
2. **一进来就能画**：启动后默认画笔，光标在画布上即为笔。没有"新建"、"添加"之类的前置步骤。
3. **讲解时界面退后**：工具栏小而稳定；演示模式下除内容外全部隐藏。
4. **模式始终可见**：当前工具在工具栏中高亮，切换时屏幕中央出现短暂提示（HUD）。光标形态随工具变化。
5. **只说用户语言**：主界面不出现修订号、文件路径、"内核"、"M0"等开发信息；诊断信息放在状态提示的 tooltip 或"关于"中。
6. **一套组件，三处复用**：画布窗口、覆盖层、演示模式使用同一工具栏组件和快捷键。

## 2. 三个界面

### 画布窗口

```text
┌●●●  标题 · 已保存                                     ┐  ← 透明标题栏，可拖动窗口
│                                                      │
│                 画布（满窗口，点阵背景）                │
│                                                      │
│     ┌────────────────────────────────────────────┐   │
│     │ ↖ ✎ ▌ ✦ ⌫ │ T ∑ │ ● ● ● ● │ ─ ━ ▬ │ ↶ ↷ │   │  ← 悬浮工具栏，底部居中
│     └────────────────────────────────────────────┘   │
└                                             100% ──┘  ← 缩放指示，点击复位
```

- 标题栏用 `titleBarStyle: Overlay`，红绿灯浮在画布上方；标题区域可拖动窗口。
- 保存状态与标题放在一起，用"圆点 + 两到四字"表示；失败时变为可点击的"重试"。
- 错误与恢复提示在顶部居中，以提示条（toast）出现，不遮挡工具栏。

### 屏幕覆盖层（M1 原型）

- 共用绘图工具栏，下方一条精简控制行：绘制／穿透切换（⌥P 或 Esc）、背景压暗、规整／删除（仅选中时出现）、清屏、帮助、结束。
- 穿透时蒙版在全局鼠标位置挖一个柔边光洞，并显示光标光环；穿透快捷键仅在穿透期间生效。
- 帮助按需经「?」打开，不自动弹出、不阻塞落笔。屏幕标注明确标为临时内容，不显示“已保存”。
- 工具栏与 HUD 放在单独的窗口，目标是对会议观众不可见（见 `docs/engineering/macos-and-privacy.md`）。

### 演示模式

- 全屏，隐藏工具栏；保留激光笔（L）与画笔快捷键；Esc 退出。

## 3. 工具栏

- **分组顺序固定**：选择与书写（选择、画笔、荧光笔、激光笔、橡皮）→ 插入（文字、图形）→ 颜色 → 粗细 → 历史（撤销、重做）。分组之间用 1px 分隔线隔开。
- **尺寸**：按钮 36×36pt，图标 20pt，圆角 `--radius-md`；工具栏高度 48pt，圆角 `--radius-lg`，带 `--shadow-floating`。
- **状态**：默认、悬停（`--color-hover`）、选中（`--color-selected` 底色 + `--color-accent` 图标）、禁用（40% 不透明度）、按下（`--color-pressed`）。
- **标签**：不在图标下方放文字。每个按钮必须有 `aria-label`，tooltip 写成"名称 快捷键"，例如"画笔 P"。
- **图标**：统一的 1.75pt 线性图标，24 网格，端点圆头。内联 SVG，不混用不同风格的图标库。

## 4. 快捷键

| 键 | 行为 | 键 | 行为 |
| --- | --- | --- | --- |
| V | 选择 | T | 文字 / 公式 |
| P | 画笔 | S | 图形 |
| H | 荧光笔 | 1–4 | 墨迹颜色 |
| L | 激光笔 | [ / ] | 减小 / 增大粗细 |
| E | 橡皮（整笔擦除） | ⌘Z / ⇧⌘Z | 撤销 / 重做 |
| 空格（按住） | 临时平移 | ⌫ | 删除所选 |
| ⌘0 | 缩放复位 | Esc | 取消当前操作 / 取消选择 |

- 文字与公式共用一个入口：输入含 LaTeX 命令、上下标或等式结构时自动按公式渲染，并在编辑框下方实时预览；中日韩文字与句子保持普通文字。
- 文本输入框聚焦、输入法组字（`isComposing`）期间，单键快捷键一律不响应。
- 触控板：双指滑动平移，捏合缩放（以指针为中心）。

## 5. 墨迹色板

墨迹色与界面色分开管理；墨迹只提供少量高对比演示色：

| 槽位 | 名称 | 存储值 | 深色画布上的显示 |
| --- | --- | --- | --- |
| 1 | 墨黑 | `#1f2329` | 显示为 `#f2f3f5`（渲染时映射，文档不变） |
| 2 | 演示红 | `#e5484d` | 原样 |
| 3 | 演示蓝 | `#2f6fed` | 原样 |
| 4 | 演示绿 | `#2b9a66` | 原样 |

- 荧光笔：同色、不透明度 0.35、宽度为画笔的 4 倍。
- 激光笔：红色核心加外发光，抬笔约 1 秒后开始渐隐，0.5 秒内消失；激光笔不写入文档。
- 粗细三档：细 2 / 中 4 / 粗 8（画布坐标单位）。

## 6. 视觉令牌

- **颜色**：只用语义令牌（`--color-canvas`、`--color-surface`、`--color-text`、`--color-accent`……），组件中禁止出现十六进制颜色。深浅两套由 `prefers-color-scheme` 切换。
- **画布底色**：浅色为 `#f5f6f7`（比纯白柔和，投屏不刺眼）；深色为 `#1b1d21`。
- **间距**：4pt 网格（4 / 8 / 12 / 16 / 24 / 32）。
- **字体**：系统字体（SF Pro / 苹方），字号 11 / 12 / 13 / 15 / 20 五档。正文 13，辅助说明 11–12。数字用 `tabular-nums`。
- **圆角**：sm 6 / md 8 / lg 12。
- **阴影**：只有悬浮层（工具栏、提示条、弹出层）使用阴影。
- **动效**：快 120ms（悬停、按下）、标准 200ms（出现、消失）。HUD 停留 700ms 后淡出。尊重 `prefers-reduced-motion`。
- **层级**：画布 0 → 对象层 1 → 实时墨迹层 2 → 悬浮界面 10 → 提示条 20 → HUD 30。

## 7. 文案

- 动词开头、短句："重试"、"已保存"、"保存失败"。
- 错误提示写清三件事：发生了什么、内容是否安全、下一步怎么做。
- 空画布只给一行轻提示，例如"直接落笔开始讲解 · T 文字 · L 激光笔"；第一笔后消失，不拦截点击。

## 8. 辅助功能

- 所有按钮有可访问名称；工具组用 `role="toolbar"`，选中态用 `aria-pressed`。
- 保存状态使用 `role="status"`；错误提示使用 `role="alert"`。
- 焦点环使用 `--color-focus`，宽度 2pt，外偏移 2pt。
- 文字对比度不低于 WCAG AA。

## 9. 评审清单（每个 UI 改动）

- [ ] 启动后无需任何点击即可落笔。
- [ ] 没有硬编码颜色、尺寸；新组件覆盖默认、悬停、选中、禁用、加载、失败状态。
- [ ] 深浅色、Retina 与非 Retina、窗口最小尺寸下都检查过。
- [ ] 中文输入法组字时不误触快捷键或提前提交。
- [ ] 主界面没有开发者信息。

## 10. 笔刷与图形补充

画笔按钮展开圆珠笔、铅笔、钢笔、记号笔选项；荧光笔保持独立入口。图形按钮展开直线、箭头、矩形、椭圆，按下拖出，抬笔完成。停笔规整为显式开关，默认关闭；保持按下 600ms 显示拟合预览，不可靠时保留原笔迹。工具栏窗口按内容调整高度，不用超大透明点击区域覆盖底层应用。
