# 验证与交付要求

> 从原根 `AGENTS.md` §11 迁出。

- 优先测试领域不变量、编辑命令、撤销重做、序列化及版本迁移；通过可替换的存储、时钟和服务接口验证真实行为。
- 持久化改动覆盖提交前后中断、日志截断、资源写入失败及恢复后再次保存等关键路径。覆盖磁盘满、权限拒绝、配置损坏及新版文件保护等失败场景。
- 涉及并发时检查多窗口编辑、过期任务返回、取消与完成竞争；涉及路径时检查中文、空格、组合字符、符号链接及位置变化。
- UI 与平台改动在实际 macOS 环境验证键盘、输入法、辅助功能、显示器与窗口行为。性能改动按基线测量。
- 屏幕共享相关改动按 `macos-and-privacy.md` 的会议软件矩阵实测，注明 macOS 与会议软件版本。
- 验证范围与改动风险相称。维护可执行的构建、测试与基准命令，不编造已通过的结果。
- 修改前阅读相关模块和现有差异，保留用户未提交的工作。改动控制在任务范围内；触及旧实现时逐步改善，记录未解决的风险。
- 交付说明包含行为变化、验证依据及实际限制。新能力考虑空状态、加载、成功、失败、取消和重试路径。
