# goal / memory 真实连写修复（2026-11-09）

本页保留 goal / memory 阶段的历史结果。后续“我们”被误作英文的中英文竞争修订、四条轨迹联合结果和最终窗口验证见 [中文连笔修复记录](mixed-connected-evaluation.md)。

用户截图写的是 `goal`。在独立验证版的已保存文档上做只读 SQLite 备份，恢复出与截图一致的 197 点连续轨迹（宽 485.07、高 361.18，宽高比 1.343）。旧版把它作为单个汉字，首选 `斌`，其次 `疵`、`科`；词内解码根本没有执行。此前 memory 的错误也属实际失败，不能用七组合成样例、41/48 组合变体或 3.90–30.71 ms 计算 p95 反驳用户反馈。

## 实现变化

- 将连写词几何入口的最小宽高比从 1.4 调到 1.1，允许同时具有上伸和下伸笔画的短词。仍要求单笔、足够弧长和明显的整体右向推进，不把所有图形直接当英文。
- 字母之间允许有界的空连接边：仅较短、基本直线且向右的连接段可不发射字母；总长度不超过全词弧长的 20%，不能从空词开始、不能留在词尾，不能跳过回环、高竖线和向左返回；付出长度惩罚。该空边只存在于识别格，不删除文档点。
- 对仅含一条轨迹的工作副本按高度归一化，按弧长重采样 512 点并量化到 1e-5；这使虚拟切点不依赖文档平移、等比缩放和沿同一线段加密采样。原始点、笔画 ID、命令与撤销单元保留。
- 保留 memory 修复的末尾下伸回勾；约束 g/q 片段不能吞掉相邻椭圆。英文词频权重从 0.25 降到 0.10，避免常见词掩盖较强字形证据。该系数来自开发调试，未做概率校准。

仍最多 25 切点、300 区间、256 条 beam。没有新增模型、运行时依赖、词条或目标单词特判；memory、goal 在修复前的词表里已存在。本轮调整直接参考这三条用户笔迹，全部结果属于开发回归。

## 工程与窗口验证

普通单元测试新增连接线不能吞字、平移/等比缩放/共线加点不改变虚拟切点的回归。显式本地模型测试继续验证三份原笔迹的首选、原笔画身份和幂等响应；原七组合成整行仍单独回归。全仓 `cargo test --offline --locked` 50 项通过（2 项模型测试默认忽略），显式模型测试另行 2/2 通过；`cargo fmt --all -- --check`、包含桌面包的 workspace/all-targets Clippy 均通过。完整 Tauri debug 验证版构建与严格签名校验通过（构建同时运行前端类型检查和 Vite 打包）。此阶段窗口尚未完成复核，随后收到“我们”误作 among 的反馈；最终窗口结果记录在后续报告中。

独立验证版更新前已完整备份已保存的修订 33；不覆盖用户画布，不关闭其他 Coboard 应用。模型、词表及来源沿用既有报告，所有推理本地完成；研究权重的分发许可仍未澄清，未打包。多笔连写、补点补横、词表外名称、英文长句和独立多人数据仍未验收，真人孤立字符 Top1 52.66% 的既有结论不变。当前仍是需用户确认的候选原型。
